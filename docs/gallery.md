# Palette gallery

Choose a palette by comparing the same code on different backgrounds. All four use the same color
roles, so switching palettes does not change what a function, type or diagnostic means. Read
[the design explanation](color-system.md) for the reasoning.

## Browse by palette

Each preview shows the same Zig source with Tree-sitter. Click a preview or palette name for more
languages, selections, diffs, diagnostics, completion, Go/Zig LSP hover examples, lualine, Neo-tree,
and terminal-app snapshots. All maintained images use the same
[reproducible capture pipeline](showcase.md).

### [Dusk](themes/dusk.md)

Violet dark background with amber types, teal functions and lavender keywords.

[![Dusk palette in Neovim](../assets/screenshots/dusk/zig.png)](themes/dusk.md)

### [Opal](themes/opal.md)

Lilac-tinted light background with apricot types, vivid violet keywords, blue calls and pink-berry fields.

[![Opal palette in Neovim](../assets/screenshots/opal/zig.png)](themes/opal.md)

### [Mira](themes/mira.md)

Lifted blue-violet dark background with softened text and matte honey, sky-blue and lavender accents.

[![Mira palette in Neovim](../assets/screenshots/mira/zig.png)](themes/mira.md)

### [Mesa](themes/mesa.md)

Faint violet-gray paper with ochre types, deeper violet keywords, petrol-blue calls and jade strings.

[![Mesa palette in Neovim](../assets/screenshots/mesa/zig.png)](themes/mesa.md)
