SETUP                                                              *flume-setup*

Install with your plugin manager, then load the theme:
>
    require("flume").setup({})
    vim.cmd.colorscheme("flume")
<

Flume targets Neovim 0.9+ and expects 'termguicolors' for accurate color.
It currently ships one dark scheme.

==============================================================================
OPTIONS                                                          *flume-options*

Defaults:
>
    require("flume").setup({
        transparent = false,
        terminal_colors = true,
        overrides = {},
        highlights = {},
        styles = {
            comments = {},
            functions = {},
            keywords = {},
            strings = {},
            types = {},
            variables = {},
        },
    })
<

transparent ~
    Removes the primary editor and sign-column backgrounds. Raised surfaces,
    selections, diffs, and diagnostic backgrounds remain visible.

terminal_colors ~
    Sets g:terminal_color_0 through g:terminal_color_15 from the palette.

Choosing an override ~

    overrides   change a semantic color across languages
    styles      add broad attributes such as italic or bold
    highlights  change one exact Neovim group

overrides ~
    Changes palette colors by semantic role. This example affects modules and
    namespaces across supported languages:
>
    require("flume").setup({
        overrides = {
            syntax_namespace = "#f48a94",
        },
    })
<
    Syntax roles include syntax_comment, syntax_function, syntax_keyword,
    syntax_namespace, syntax_string, and syntax_type. State roles include
    error, warning, success, info, match, and diff_add/diff_change/diff_delete.
    See lua/flume/palette.lua and docs/color-system.md for the full contract.

styles ~
    Adds broad text attributes to syntax roles.
>
    require("flume").setup({
        styles = {
            comments = { italic = true },
            keywords = { bold = true },
        },
    })
<

highlights ~
    Changes an exact, case-sensitive Neovim group or Tree-sitter capture.
    Values may be tables or functions that receive the resolved palette.
>
    require("flume").setup({
        highlights = {
            Comment = { fg = "#f48a94" },
            ["@comment"] = function(colors)
                return { fg = colors.syntax_comment, italic = true }
            end,
        },
    })
<
    Comment is the legacy syntax group; ["@comment"] is the Tree-sitter
    capture. Use :Inspect under the cursor or :highlight GroupName to find the
    active group.

==============================================================================
COMMANDS                                                        *flume-commands*

:FlumeReload                                                      *:FlumeReload*
    Reload the editor theme and notify ColorScheme integrations.

:FlumeCompile                                                    *:FlumeCompile*
    Regenerate files under extras/.

:FlumeInstallExtras [app]                                  *:FlumeInstallExtras*
    Symlink generated extras into standard config locations. Supported app
    arguments: ghostty, tmux, lsd. With no argument, installs all supported
    extras.

:FlumeExtras                                                      *:FlumeExtras*
    Open copy-paste install commands for extras.

:checkhealth flume                                           *flume-checkhealth*
    Check terminal color support and generated extra files.

==============================================================================
EXTRAS                                                            *flume-extras*

Generated files are checked into extras/ and can be used without compiling:

    APP       FILE                         ACTIVATION
    Ghostty   extras/ghostty/flume         set theme = flume
    Tmux      extras/tmux/colors.conf      source ~/.tmux/flume-theme.conf
    LSD       extras/lsd/colors.yaml        install to the standard color path
    Pi        extras/pi/flume.json          copy/link into the themes directory
    Tuxedo    extras/tuxedo/flume.toml      copy/link into the themes directory

The Tmux file defines thm_* color variables; it is not a complete status-line
configuration. Automated installation supports Ghostty, Tmux, and LSD and
refuses to replace regular files.

If you edit lua/flume/palette.lua, run :FlumeCompile to regenerate extras.
