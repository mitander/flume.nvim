SETUP                                                              *flume-setup*

Install with your plugin manager, then load the theme:
>
    require("flume").setup({})
    vim.cmd.colorscheme("flume")
<

Flume targets Neovim 0.9+ and expects 'termguicolors' for accurate color.

==============================================================================
OPTIONS                                                          *flume-options*

Defaults:
>
    require("flume").setup({
        transparent = false,
        terminal_colors = true,
        overrides = {},
        highlights = {},
        styles = {
            comments = {},
            functions = {},
            keywords = {},
            strings = {},
            types = {},
            variables = {},
        },
    })
<

transparent ~
    Removes editor background colors.

terminal_colors ~
    Sets g:terminal_color_0 through g:terminal_color_15 from the palette.

overrides ~
    Overrides palette keys from lua/flume/palette.lua.
>
    require("flume").setup({
        overrides = {
            accent = "#73a6b6",
            syntax_namespace = "#f48a94", -- @module and @namespace
        },
    })
<
    Semantic syntax keys include syntax_attribute, syntax_boolean,
    syntax_comment, syntax_doc_comment, syntax_constant, syntax_function,
    syntax_type, syntax_keyword, syntax_namespace, syntax_primary,
    syntax_property, syntax_punctuation, syntax_punctuation_bracket,
    syntax_punctuation_special, syntax_string, and syntax_special.

highlights ~
    Overrides exact, case-sensitive Neovim highlight groups after Flume has
    applied its defaults. Values may be highlight tables or functions that
    receive the resolved color table.
>
    require("flume").setup({
        highlights = {
            Comment = { fg = "#333333", bg = "#ffff00" },
            ["@comment"] = function(c)
                return { fg = c.syntax_comment, italic = true }
            end,
            FloatBorder = function(c)
                return { fg = c.accent, bg = c.bg }
            end,
        },
    })
<
    Use Comment (singular, capitalized) for the legacy syntax group and
    ["@comment"] for the Tree-sitter capture. "comments" is a styles role, not
    a highlight group. Use :Inspect or :highlight GroupName to find the active
    group.

styles ~
    Adds style attributes to broad syntax roles.
>
    require("flume").setup({
        styles = {
            comments = { italic = true },
            keywords = { bold = true },
        },
    })
<

==============================================================================
COMMANDS                                                        *flume-commands*

:FlumeReload                                                      *:FlumeReload*
    Recompile extras, reload the theme, and refresh Ghostty/Tmux when possible.

:FlumeCompile                                                    *:FlumeCompile*
    Regenerate files under extras/.

:FlumeInstallExtras [app]                                  *:FlumeInstallExtras*
    Symlink generated extras into standard config locations. Supported app
    arguments: ghostty, tmux, lsd. With no argument, installs all supported
    extras.

:FlumeExtras                                                      *:FlumeExtras*
    Open copy-paste install commands for extras.

:checkhealth flume                                           *flume-checkhealth*
    Check terminal color support and generated extra files.

==============================================================================
EXTRAS                                                            *flume-extras*

Generated files are checked into extras/:

    extras/ghostty/flume
    extras/tmux/colors.conf
    extras/lsd/colors.yaml
    extras/pi/flume.json
    extras/tuxedo/flume.toml

If you edit lua/flume/palette.lua, run :FlumeCompile or :FlumeReload.
